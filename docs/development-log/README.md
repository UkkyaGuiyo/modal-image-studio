# 開発ログ（試行錯誤の記録）

この道具を作る過程で実際に回した実験と、その結果の記録です。
成功した手順だけでなく、**失敗・原因・直し方**まで含めて残してあります。
手順書のトラブルシューティングは、ここにある試験IDを根拠にしています。

記録の標準項目：試験ID／日時／目的／操作／版数／期待結果／実際の結果／失敗内容／推定原因と確認方法／修正／再試験／GPU時間と費用／判定。
原因が分からないものは「原因不明」と書く決まりで、推測を確定原因として書きません。
