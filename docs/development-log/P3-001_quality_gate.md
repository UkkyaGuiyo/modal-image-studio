- 失敗・観察事項（トラブルシューティング／Howtoの素材）：
  1. **Exploreの弱点**：被写体の移動や視点変更の指示が通りにくい。「箱の外に出る」は4枚とも不発（庭と毛糸は出た）、「対岸からの視点」も不発で元の構図のまま。季節・時刻・場面の変更は通る。→ Exploreは「場面を変える」用途に限定して案内する
  2. **作風の漂移**：Exploreでフラットなイラストが指示なく写真風に変わった（R1）。画風を保ちたい場合はプロンプトに作風を明記する
  3. **疑似文字**：浮世絵化で読めない漢字風の落款・題字が付いた。文字が不要な場合は `no text` を明記する
  4. **枠アーティファクト**：R1 Explore の img_002 に額縁状の枠が出た（36枚中1枚）
  5. **Modalの同時起動制限**：`modal run` を4本同時に起動したら `App create rate limit exceeded (RESOURCE_EXHAUSTED)` で1本が失敗した。直列実行に変えて全て成功。→ 手順書では「実行は1本ずつ」を明記する
