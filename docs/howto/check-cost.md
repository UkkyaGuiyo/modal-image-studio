# Howto：費用を確認する

## 1回ごとの費用（いちばん速い確認）

生成・ブレンドのたびに、標準出力と manifest に費用が出ます。

- studio.py：run フォルダの `manifest.json`（`load_seconds` と各画像の `seconds`）と、実行時の標準出力 JSON の `est_cost_usd`
- poster.py：`poster_manifest.json` の `blend.est_cost_usd`

目安（実測。いずれもモデルキャッシュ後のGPU費用の推定）：候補8枚 ≈ $0.011／ブレンド1枚 ≈ $0.006／36枚級の編集一式 ≈ $0.11。初回実行は読み込み（約62秒）込みで、候補8枚 ≈ $0.027〜0.029（目安 約$0.03）です。なお `est_cost_usd` はGPU費用の推定であり、CPU・メモリ等を含む総請求額ではありません（総額は下記の請求ベースで確認してください）。

## 当月の合計（公式の数字）

```bash
modal billing summary
```

ダッシュボードの Billing でも確認できます。コマンドと食い違う場合はダッシュボードを正としてください。

## 増えすぎを防ぐ運用

- 実行は1本ずつ。結果と費用を見てから次を出す
- `--model base` は1枚67秒と高くつくので、実験以外では使わない
- 予算の上限はダッシュボードの Spend limit（03 章、人間が設定）。上限に近づいたら人間に報告する

詳しくは [13 章](../manual/13_cost_and_stop.md)。
