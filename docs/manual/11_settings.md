# 11 解像度・速度・費用・設定

この章は参照用の章です。数値はすべて開発時の実測（Modal A10）です。

## サイズ（縦横比）

| プリセット | 寸法 | 向いている用途 |
|---|---|---|
| 1:1 | 1024×1024 | 標準 |
| 3:4 | 896×1184 | 縦ポスター |
| 4:3 | 1184×896 | 横長イラスト |
| 2:3 | 832×1248 | ポスター（A判比率に近い） |
| 3:2 | 1248×832 | 写真風の横長 |
| 16:9 | 1376×768 | バナー・スライド |
| 9:16 | 768×1376 | スマホ壁紙・縦動画サムネイル |

全プリセットが指定寸法どおりに出力されることを実測済み（BENCH-001）。`--size 1200x900` のような直指定も可能。

## 速度（実測）

| 項目 | 実測 |
|---|---|
| モデル読み込み（初回、ダウンロード込み） | 62.05 秒 |
| モデル読み込み（2回目以降、Volume キャッシュ） | 8.2〜9.3 秒 |
| 生成 1024×1024・4 steps | 3.3〜4.2 秒/枚 |
| 参照編集 | 6.22 秒/枚 |
| ブレンドパス（poster.py、6 steps） | 9〜17 秒/枚 |
| Base モデル生成（50 steps） | 67 秒/枚 |

## 費用（実測、A10 単価 $0.000306/秒で換算）

| 作業 | 概算 |
|---|---|
| 候補8枚 | 約 $0.011 |
| 候補16枚 | 約 $0.02 |
| 品質ゲート級の36枚編集 | 約 $0.11 |
| ポスターのブレンド1枚 | 約 $0.006 |

この表の金額は、モデルキャッシュ後のGPU費用を A10 単価で換算した推定です。初回実行は読み込み（約62秒）込みで、候補8枚で約 $0.027〜0.029（目安 約$0.03）になります。また、GPU費用のみの推定であり、CPU・メモリ等を含む総請求額ではありません。

月 $30 クレジットでの枚数は、起動オーバーヘッドの仮定で約4,480〜13,200枚/月という**試算**があります（E.L.I.S. 試算。実測値ではないので、実際の消費は manifest と請求で確認すること。13 章）。

## 設定の考え方

- **steps / guidance（蒸留モデル）**：既定の 4 steps / guidance 1.0 が標準。蒸留モデルは guidance を上げても効き方が通常モデルと違うため、基本は既定のまま使う
- **Base モデル（`--model base`）**：50 steps / guidance 4.0 が標準的な使い方だが、計算量は蒸留版の約20倍。日本語テキストの精度改善も無かった（TEXT-001）。通常の制作では使わず、比較実験のときだけにする
- **seed**：同じプロンプト＋同じ seed で同じ条件の再実行ができる（ソフトウェアや環境の差で出力が変わることはある。00 章の注意書き参照）。気に入った絵の条件は manifest.json に全部残っている
- **同時実行は1本**：速くしたいからと並列に `modal run` を出すと、レート制限で失敗する（P3-001）。バッチは1回の実行にまとめる（--count や --prompts-json）のが速くて安い
