# 09 コンタクトシートと選択

## 手順1：候補を一覧で提示する

- 目的：人間が比べられる形で候補を見せる
- 前提条件：08 章の一括生成が終わっている
- 実行主体：Muse
- コマンド：なし（対象 run の `contact_sheet.png` を開いて見せる。個別の拡大が必要なら img_00X.png も見せる）
- 成功条件：人間が全候補を確認できた
- 失敗時の切り分け：コンタクトシートのサムネイルは小さい（384px）。細部の判断は元画像で
- 次のステップ：手順2

## 手順2：選択を記録する

- 目的：**人間が選んだ**1枚を selection.json に記録し、展開の起点を固定する
- 前提条件：人間が「img_00X」と明示した
- 実行主体：Muse（記録のみ。選ぶのは人間）
- コマンド：
  ```bash
  python3 select.py --run runs/<日時>_<名前> --list
  python3 select.py --run runs/<日時>_<名前> --pick img_003 --note "理由メモ"
  ```
- 成功条件：`selection.json` が作られ、`decided_by: human` と picked_path / prompt / seed が記録される
- 失敗時の切り分け：存在しないIDを指定するとエラーで止まり、利用可能なID一覧が出る
- 次のステップ：10 章（展開）

## 手順3：選び直す

- 目的：気が変わった場合に選択を差し替える
- 前提条件：selection.json が既にある
- 実行主体：Muse（記録のみ）
- コマンド：手順2と同じ `--pick` を新しいIDで実行する
- 成功条件：前の選択が `history` に残り、新しい選択が現在値になる
- 失敗時の切り分け：—
- 次のステップ：10 章

注意：Muse が「おすすめ」を聞かれたら、特徴の説明はしてよいが、最終決定は人間に返してから記録する（01 章）。
