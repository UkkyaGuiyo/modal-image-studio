# 03 Modal 登録・支払い・予算

この章の操作は**人間がブラウザで行います**。Muse は案内と確認だけを行い、支払い情報には一切触れません。

## 手順1：Modal に登録する

- 目的：Modal アカウントを作り、Starter プラン（月 $30 クレジット）を使える状態にする
- 前提条件：メールアドレスまたは GitHub / Google アカウント
- 実行主体：**人間**（ブラウザ操作）
- コマンド：なし（https://modal.com のサインアップ画面で登録）
- 成功条件：Modal のダッシュボードにログインできる
- 失敗時の切り分け：認証メールが届かない場合は迷惑メールフォルダを確認する
- 次のステップ：手順2

## 手順2：支払い方法を登録する

- 目的：Starter の $30 クレジットを有効化する（登録しないと使えない）
- 前提条件：手順1が完了。有効なクレジットカード等
- 実行主体：**人間**（Muse にカード情報を渡さない）
- コマンド：なし（ダッシュボードの Billing / Settings から登録）
- 成功条件：Billing 画面で支払い方法が登録済みと表示される
- 失敗時の切り分け：カードが拒否される場合はカード会社の制限を確認する。Muse はこの画面の情報を読み取らない
- 次のステップ：手順3

> 正直な注意：「月 $30 無料」と言っても、**支払い方法の登録は必須**です。クレジットを超えた分は従量課金になるため、次の予算設定が安全装置になります。

## 手順3：予算（Spend limit）を設定する

- 目的：意図しない従量課金を防ぐ上限を先に決める
- 前提条件：手順2が完了
- 実行主体：**人間**（金額の決定も人間）
- コマンド：なし（ダッシュボードの Billing / Budgets から設定）
- 成功条件：上限額が設定され、Muse と共有されている（金額そのものは Git に書かない）
- 失敗時の切り分け：設定項目が見つからない場合はダッシュボードの Billing 配下を探す。画面構成は変わることがある
- 次のステップ：04 章（CLI 導入）

## この章の費用感

- 登録自体は無料。$30 クレジットは毎月付与される
- 開発時の実測では、通常の生成作業は1回あたり数セント（8枚で約 $0.011）。まず上限を小さく設定し、足りなくなったら人間が上げる運用が安全
