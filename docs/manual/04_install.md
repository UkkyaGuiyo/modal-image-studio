# 04 Git・Python・Modal CLI 導入

## 手順1：Python と pip を確認する

- 目的：ローカルツールの実行基盤を確認する
- 前提条件：02 章の確認が完了
- 実行主体：Muse
- コマンド：
  ```bash
  python3 --version
  ```
- 成功条件：Python 3.10 以上と表示される（開発時は 3.12）
- 失敗時の切り分け：`python3` が無い場合は OS のパッケージマネージャか python.org から導入する。Windows では `python` コマンドの場合がある
- 次のステップ：手順2

## 手順2：Modal CLI と Pillow を入れる

- 目的：`modal` コマンドと、ローカルで使う画像ライブラリを導入する
- 前提条件：手順1が完了
- 実行主体：Muse
- コマンド：
  ```bash
  pip install modal pillow
  modal --version
  ```
- 成功条件：バージョンが表示される（開発時は modal client 1.6.3。数字が違っても構わない）
- 失敗時の切り分け：pip の権限エラーが出る場合は仮想環境（venv）を作ってその中に入れる。`pip install --user` でもよい
- 次のステップ：手順3

## 手順3（任意）：Git を確認する

- 目的：リポジトリの取得・更新を Git で行えるようにする
- 前提条件：なし（ZIP で取得する場合は不要）
- 実行主体：Muse
- コマンド：
  ```bash
  git --version
  ```
- 成功条件：バージョンが表示される
- 失敗時の切り分け：無ければ 06 章で ZIP 展開の手順を使う
- 次のステップ：05 章（認証と接続テスト）
