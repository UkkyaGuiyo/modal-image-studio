# 07 最初の1枚

## 手順1：最小の生成を実行する

- 目的：パイプライン全体（認証→GPU実行→保存）が通ることを、最小コストで確認する
- 前提条件：05 章の接続テストまで完了。**ここから小さな課金が発生する**（1枚＋初回読み込みで約 $0.03）
- 実行主体：Muse
- コマンド（リポジトリのルートで、1本だけ実行し、終わるまで次を出さない）：
  ```bash
  modal run studio.py --mode generate --count 1 --run-name first
  ```
- 成功条件：標準出力に JSON（run_dir / count / per_image_seconds / est_cost_usd など）が表示され、`runs/<日時>_first/` に `img_001.png` と `manifest.json` と `contact_sheet.png` ができる
- 失敗時の切り分け：
  - `RESOURCE_EXHAUSTED` → 同時に別の `modal run` が走っていないか確認し、1本に絞る（P3-001）
  - 認証エラー → 05 章手順1をやり直す
  - 初回は重みのダウンロードで読み込み約62秒かかるのが正常（P1-001）。2回目以降は約9秒
- 次のステップ：手順2

## 手順2：結果を人間に見せる

- 目的：生成物を確認し、パイプラインの出力形式に慣れる
- 前提条件：手順1が成功
- 実行主体：Muse（提示）＋人間（確認）
- コマンド：なし（`runs/<日時>_first/img_001.png` を開いて見せる）
- 成功条件：人間が画像を確認できた
- 失敗時の切り分け：画像が真っ黒・真っ白の場合は seed を変えて再実行し、それでも続くなら [トラブルシューティング](../troubleshooting.md) を見る
- 次のステップ：08 章（一括生成）

参考実測（開発時）：生成 3.83 秒/枚、VRAM 最大 18.6GB（A10 の 24GB に収まる）。
