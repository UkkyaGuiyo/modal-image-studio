# 02 環境・ツール・アカウント

## 手順1：必要なものをそろえる

- 目的：実行に必要な環境・アカウント・ツールを洗い出し、不足を先に潰す
- 前提条件：なし（この章が起点）
- 実行主体：Muse（確認）＋人間（アカウント作成の判断）
- コマンド：なし（下の表で確認）
- 成功条件：表の全項目が「ある」または「これから作る（担当章が決まっている）」になる
- 失敗時の切り分け：OS が Windows の場合、コマンドは PowerShell でも動くが、パス区切りと環境変数の書き方に読み替えること
- 次のステップ：不足があれば該当章へ。全部そろえば 07 章から生成に入れる（初回は下記の実行順序で 03〜06 を実施）

> **初回セットアップの実行順序**：章番号の順ではなく、00 → 01 → 02 → 03 → 04 → 05 章 手順1（Modal 認証）→ 06 章（リポジトリ取得・依存導入）→ 05 章 手順2・3（接続テスト・状態確認）→ 07 → 08〜17 の順に進めます。05 章の接続テストは 06 章で取得したファイルを使うため、この入れ替えが必要です（05 章・06 章の本文にも注意書きがあります）。

| 必要なもの | 用途 | 備考 |
|---|---|---|
| PC（Windows / macOS / Linux） | CLI の実行場所。GPU は不要（計算は Modal 側） | |
| Python 3.10 以上 | ローカルツールの実行 | 開発時は 3.12 |
| Modal アカウント | GPU 実行と $30 クレジット | 作成は 03 章。**支払い方法の登録が必須** |
| Chromium または Chrome | ポスター文字の描画（poster.py） | 自動検出される。無ければ導入する |
| 日本語フォント（Noto Sans CJK JP / Noto Serif CJK JP） | ポスターの日本語表示 | 無いと文字が豆腐（□）になる |
| Git（任意） | リポジトリの取得・更新 | ZIP 展開でも可（06 章） |

## 手順2：モデルの入手性を確認する

- 目的：使うモデル（FLUX.2 Klein 4B）が自分の環境から取得できることを知っておく
- 前提条件：手順1が完了
- 実行主体：Muse（説明のみ。この時点ではダウンロードしない）
- コマンド：なし（初回の `modal run` で自動的にダウンロードされ、Modal の Volume にキャッシュされる）
- 成功条件：モデルの置き場所が Modal 側 Volume（`flux2-klein-weights`）であることを理解している
- 失敗時の切り分け：開発環境では Hugging Face のトークンなしでダウンロードできた。もし認証エラーが出たら、モデルの配布条件が変わった可能性があるので、Hugging Face のモデルページで最新の配布条件を確認する
