# 00 概要と比較

この章は「読むだけ」の章です。実行手順はありません。

## この道具を一言で言うと

画像を大量に作る道具ではなく、気に入った画像を起点に、デザインを育てていくための制作パイプラインです。

画像生成AIを使っていて、こんな経験はないでしょうか。

「この画像は気に入った。でも、色を少し変えたものも見たい」
「同じキャラクターで、昼と夜のバージョンを作りたい」
「候補を何枚も比較して、一番よいものを選びたい」
「画像の雰囲気はよいのに、日本語のタイトルだけが読めない」

このシステムは、そうした作業を繰り返しやすくするために作られています。

仕組みは3つのプログラムに分かれています。

studio.py： FLUX.2 Klein 4Bを使い、画像を生成したり、選んだ画像を参照して別の案を作ったりする。

select.py： 人間が選んだ画像を記録し、次の生成でその画像を親として指定できるようにする。

poster.py： 生成画像に文字を正確に配置し、必要に応じて背景と文字の境界をAIで馴染ませ、ポスターとして仕上げる。

生成した画像には、プロンプト、seed、使用モデル、設定、親画像との関係、処理時間などが記録されます。これにより、気に入った案を後からたどり、同じ設定を使って再度試すことができます。

ここで大切なのは、AIにすべてを決めさせないことです。

最初の候補を作るのはAI。方向性を決めるのは人間。選んだ方向性を広げるのは再びAI。そして、最終的な文字組みや仕上げは専用ツールが担当します。

無料版ChatGPTの画像生成と競争するためのものではありません。手軽に1枚を作りたいならChatGPTの方が便利な場面もあります。この道具が得意なのは、複数の候補を比較し、選んだ画像を軸に何度も展開するような制作です。

この章では、その能力と限界、費用、無料版ChatGPTとの違いを先に説明します。実際の操作に入る前に、自分の用途に合っているかを確認してください。

## これは何か

自分の Modal アカウントの月 $30 クレジットを使い、FLUX.2 Klein 4B という画像モデルで
「生成 → 人間が選ぶ → 選んだ画像から展開 → ポスターに仕上げる」を繰り返す道具です。

- `studio.py`：テキスト生成と参照画像からの編集（バリエーション展開）
- `select.py`：人間の選択を記録する
- `poster.py`：日本語タイトルなどを正確に合成し、必要ならAIで馴染ませる

## できること（実測済み）

- 1024×1024 を中心に7種の縦横比で、1回に8枚（推奨最大16枚）の候補生成。1枚あたり3.3〜4.2秒
- 編集モードの品質ゲート結果（開発ログ P3-001）：PreserveとRestyleは品質ゲートで各12/12の満点通過。Exploreは平均4.0/6で、指示追随に課題が残る。編集内容によって結果は異なり、被写体の移動や視点変更には既知の制限がある
- 作風プリセット11種（水彩・浮世絵・サイバーパンク等の画風8種＋強いデザイン言語3種）
- 日本語ポスター：縦書き・ルビ・日英混植まで正確に合成できる（HTML/CSS方式）
- seed、モデル、プロンプト、生成設定を記録し、同じ条件で再実行できる。ソフトウェアやモデルのバージョン、実行環境の差によって出力が変わる可能性があり、完全なピクセル一致を保証するものではない

## できないこと・苦手なこと（実測済み、先に言っておく）

- **日本語の文字をモデルに直接描かせることはできない**（疑似漢字になる。3方式で合計0/10、開発ログ TEXT-001）。合成方式で対応する
- **被写体の「移動」ができない**（消えずに増える）。「消して描き直す」手順で対応する（開発ログ BENCH-001）
- **視点変更（対岸から見る等）が通らない**。場面・季節の変更で代替する
- 英語の長いタイトル（30字超）は生成で直接描くと誤字が出始める。合成方式が確実
- Modal 側の画質が他のサービスより高い保証はない。利点は「枚数の融通・制御性・再現性・履歴管理」

## 無料版 ChatGPT との比較（要約）

結論だけ先に言うと、**手軽さと対話的な高品質制作は無料版 ChatGPT、候補を何十枚も作って選び繰り返す用途は本道具**です。詳しくは [docs/comparisons/chatgpt-free-vs-modal.md](../comparisons/chatgpt-free-vs-modal.md)。

| 観点 | 無料版 ChatGPT（Images 2.6） | 本道具（Modal＋Klein 4B） |
|---|---|---|
| 始めやすさ | すぐ使える | 登録・支払い方法・CLI導入の手間がある |
| 枚数 | 無料枠の固定枚数は公式非公開 | 月 $30 クレジット内で日次上限なし（試算で月 数千枚規模） |
| 文字入り画像 | ChatGPT Images 2.6は画像内の文字追加に対応している。日本語を含む文字表現にも利用できるが、正確な文字列の再現は出力ごとに確認する必要がある | 日本語は合成方式が必要（手順は確立済み） |
| 複雑な指示・編集の一貫性 | 強い | 得意・不得意がはっきりしている（10章） |
| 再現性 | seed 等の設定は非公開 | seed・モデル・設定をすべて記録・制御できる |
| 速度 | 生成に数分かかる場合あり | 1枚あたり数秒（読み込み除く） |

## 費用の目安（GPU費用（推定））

| 作業 | GPU費用（推定） |
|---|---|
| 候補8枚の生成 | 約 $0.011 |
| 参照編集1枚 | 約 $0.01〜0.02（読み込み共有時） |
| ポスターのブレンド1枚 | 約 $0.006 |
| モデル読み込み | 初回約62秒（ダウンロード込み）、2回目以降は約9秒 |

なお、上の金額はいずれもモデルキャッシュ後のGPU費用の推定です。初回実行はモデルの読み込み（約62秒）込みで、候補8枚で約 $0.027〜0.029（目安 約$0.03）かかります。また、GPU費用の推定であり、CPU・メモリ等を含む総請求額ではありません（請求ベースの確認は13章）。

poster.py の費用区分：`render`（文字レイヤーの描画と合成）はローカルの Chromium で行うため、Modal の GPU 費用はかからない。GPU 費用が発生するのは `blend`（文字の周辺を AI で馴染ませる処理）だけなので、ポスターを1枚作るたびに必ず GPU 費用がかかるわけではない。

モデル選択：既定は蒸留版（Distilled）。Base 版（`--model base`）も実測したが、1枚67秒（蒸留版の約20倍の計算量）で精度の改善は確認できなかったため、通常の制作では使わない（開発ログ TEXT-001。設定の詳細は 11 章）。

月間の枚数試算や設定の詳細は 11 章。開発経緯と失敗記録は 15 章。
